# skills

Agent Skills for Cursor, Claude Code, Codex, and other agents that support [Agent Skills](https://agentskills.io).

## Install

```bash
npx skills add Ankit-Barsainya-SP/skills -g
```

The `skills` CLI copies these into each local agent path (`~/.claude/skills/`, `~/.cursor/skills/`, etc.).

## Skills

### `/grill-me`

A relentless interview to sharpen a plan or design. Invoke explicitly (`/grill-me` or "grill me on this").

Depends on the `grilling` skill (included in this repo).
